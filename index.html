2. Responzivní komponenty Bootstrap

Postup plnění projektu85 %
Komponenty i formuláře jsou zprovozněny, zbývá finální ověření odkazů na serveru.
Bootstrap 5

Zajišťuje čistou responzivitu, mřížkový systém (grid) a základní styl formulářů.

Tom Select

Umožňuje přehledný vícenásobný výběr položek s fulltextovým vyhledáváním.

TinyMCE

Plnohodnotný WYSIWYG editor pro snadné formátování textových zpráv.
